RESUMEN RAPIDO
==============

1. Descomprimir esta carpeta en:   C:\agente-zebra

   No usar Escritorio, Documentos ni Descargas. El agente corre con la
   cuenta de sistema de Windows, que no siempre alcanza esas carpetas.
   Puede funcionar al instalar y dejar de funcionar al reiniciar.

2. Abrir PowerShell COMO ADMINISTRADOR
   (clic derecho en el boton de Inicio > Terminal (Administrador))

3. Escribir estos dos comandos:

       cd C:\agente-zebra
       python setup.py

   Seguir las preguntas en pantalla. Al final dice LISTO.

4. Reiniciar la PC y comprobar:

       cd C:\agente-zebra
       python setup.py estado

   Los puntos [1] y [2] tienen que decir OK.
   Este paso no es opcional: es la prueba de que arranca solo.


LOS TRES COMANDOS
=================

    python setup.py                 Instala
    python setup.py estado          Muestra si esta funcionando
    python setup.py desinstalar     Saca el arranque automatico


SI ALGO FALLA
=============

Ejecutar  python setup.py estado  y leer el punto [4]: ahi el agente
escribe en castellano que fue lo que paso.

El registro completo esta en el archivo agente.log, en esta carpeta.

Si Windows no reconoce el comando "python", probar con "py" en su lugar.
Si tampoco funciona, falta instalar Python marcando la casilla
"Add Python to PATH".
