NAVEGACIÓN - ANTES vs DESPUÉS
================================================================================

ANTES:
------
Configuración
  ├── Productos           (VISIBLE)
  ├── Configuración Zebra (VISIBLE)
  ├── Categorías          (OCULTO)
  ├── Modelos             (OCULTO)
  └── Composiciones       (OCULTO)

DESPUÉS:
--------
Productos              ← NUEVO GRUPO
  ├── 1. Categorías     (AHORA VISIBLE con heroicon-o-tag)
  ├── 2. Modelos        (AHORA VISIBLE con heroicon-o-squares-2x2)
  └── 3. Productos      (MOVIDO CON heroicon-o-cube)

Configuración          ← SIMPLIFICADO
  └── Configuración Zebra (MANTIENE heroicon-o-printer)

================================================================================
FORMULARIO DE PRODUCTOS - ANTES vs DESPUÉS
================================================================================

ANTES - Orden confuso:
  1. Modelo*         (Select - tenías que elegir modelo sin saber qué categoría)
  2. Categoría*      (Select - después de haber elegido modelo)
  3. Nombre...

DESPUÉS - Orden lógico:
  1. Categoría/Empresa*    (Select - primero elegir empresa/categoría)
  2. Modelo de colchón*    (Select - luego elegir modelo de esa empresa)
  3. Nombre del producto*
  4. Nombre comercial*
  ...
  7. Imagen de la etiqueta (logo)  ← Ahora dice "imagen de LA ETIQUETA" (claro)

  [Confirmar]

Resultado: 
  ✓ Se envía ETIQUETA DE PRUEBA a impresora
  ✓ Muestra "ETIQUETA DE PRUEBA" como título
  ✓ Muestra logo FLEX (no logo Paraíso)
  ✓ Muestra datos del producto:
     - Modelo: FLEX SUPER KING
     - Código: FLEX-SK-200
     - Medidas: 200x190x22 cm (o lo que esté configurado)
     - Categoría: FLEX COLCHONES
  ✓ Muestra datos de conexión (IP/USB)
  ✓ Muestra fecha/hora
  ✓ Tiene borde visible

  Cantidad: 50
  [Guardar]

  ✓ Se generan 50 etiquetas con seriales únicos
  ✓ Cada etiqueta mostrará LOGO FLEX (no Paraíso)
  ✓ Se auto-imprimen (según configuración)
  ✓ En "Lotes de Etiquetas" ves el lote con estado "Impreso"
